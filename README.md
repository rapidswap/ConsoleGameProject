# ConsoleGameProject 🎮

이 프로젝트는 하나의 공통된 **콘솔 게임 엔진(CraftEngine)**을 기반으로 제작된 **3개의 개별 게임**을 포함하고 있는 통합 프로젝트입니다. C++를 기반으로 개발되었으며, 터미널/콘솔 환경에서 동작하는 게임을 쉽게 만들고 실행할 수 있도록 설계되었습니다.

## 📂 프로젝트 구조

프로젝트는 크게 1개의 핵심 엔진과 이를 활용한 3개의 게임으로 구성되어 있습니다.

- **`CraftEngine` (게임 엔진)**
  - 모든 게임의 뼈대가 되는 자체 제작 콘솔 게임 엔진입니다.
  - 화면 렌더링(Render), 물리(Physics), 수학 연산(Math), 사용자 입력 처리(Input), 게임 루프(Engine/Core) 등 게임 제작에 필요한 핵심 기능들을 담당합니다.

- **`Game` (기본 게임 프로젝트)**
  - `CraftEngine`을 활용하여 만든 기본적인 게임 프로젝트입니다.
  - 엔진을 활용한 기본적인 액터(Actor)와 레벨(Level) 구성을 확인할 수 있는 예제 역할을 합니다.

- **`PEACEMAKER` (피스메이커)**
  - 고유의 테마와 게임 로직을 가진 세 번째 게임 프로젝트입니다.
  - 다양한 액터(Actor) 상호작용 및 레벨 구성을 포함하고 있습니다.

- **`ShootingGame` (슈팅 게임)**
  - 전통적인 형태의 콘솔 슈팅 게임 프로젝트입니다.
  - 플레이어 이동, 발사체(총알) 생성, 충돌 판정 등 슈팅 게임의 필수 요소들을 직접 플레이해 볼 수 있습니다.

## 🛠️ 개발 환경 및 실행 방법

- **사용 언어**: C++
- **IDE**: Visual Studio 2022 이상 권장 (`ConsoleGameProject.slnx` 솔루션 파일 제공)
- **실행 방법**:
  1. `ConsoleGameProject.slnx` 파일을 Visual Studio로 엽니다.
  2. 솔루션 탐색기에서 플레이하고 싶은 게임 프로젝트(`Game`, `PEACEMAKER`, `ShootingGame` 중 하나)를 우클릭합니다.
  3. **"시작 프로젝트로 설정(Set as StartUp Project)"**을 클릭합니다.
  4. `F5` 키(또는 상단의 로컬 Windows 디버거 버튼)를 눌러 게임을 빌드하고 실행합니다.

## 💡 초보자를 위한 코드 탐험 가이드

이 프로젝트는 **"게임 엔진을 구축하고, 그 엔진을 활용해 여러 게임을 찍어내는 방법"**을 이해하기 좋은 구조로 되어 있습니다. 코드를 처음 보신다면 다음 순서로 살펴보시는 것을 추천합니다.

1. **CraftEngine의 `Engine` 및 `Core` 폴더**: 엔진의 초기화 과정과 무한 반복되는 게임 루프가 어떻게 작동하는지 이해합니다.
2. **각 게임의 `Main.cpp`**: 개별 게임 프로젝트가 엔진을 어떻게 가져와서 실행시키는지 확인합니다.
3. **각 게임의 `Actor`와 `Level` 폴더**: 화면에 그려지는 플레이어, 적, 배경 등이 어떻게 구현되어 있는지 살펴봅니다.
