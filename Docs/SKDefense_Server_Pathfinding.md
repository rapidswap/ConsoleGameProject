# SKDefense 서버 길찾기

온라인 게임에서는 `GameRoom`이 맵, 터렛, 살아 있는 몬스터의 위치와 경로를 소유한다. 클라이언트는 서버가 보낸 경로와 위치를 표시한다. 오프라인 게임은 공통 `ServerCore/Common/Pathfinding.h`의 최적화된 A*를 사용한다.

## 처리 흐름

1. 게임 시작 전에 서버가 `Assets/SK_Defense_Map.txt`를 로드한다. 직사각형 맵, 최대 4,096칸, 스폰과 목표의 연결을 검증한다. 서버 빌드 시 실행 파일 옆의 공용 Assets 폴더로 맵을 복사한다.
2. 설치 요청은 서버 방 락 안에서 2×2 바닥, 스폰/몬스터 점유, 골드와 연결성을 확인한다. 목표에서 한 번 flood fill하여 모든 스폰과 살아 있는 몬스터가 목표에 도달할 수 있는지 검사한다. 실패하면 맵과 골드는 원상태를 유지한다.
3. 설치·판매·합성 결과를 먼저 전송하고, 맵 버전을 올린 뒤 살아 있는 몬스터의 경로를 다시 계산한다. 합성은 기존 규칙대로 같은 속성/성급 세 개를 모아 가장 오래된 터렛을 승급한다.
4. 서버가 몬스터를 소환한 직후 경로를 보낸다. 서버 타이머가 경로를 따라 위치를 갱신하며, 이동한 경우에만 위치 패킷을 보낸다. 아지트 도착과 체력 감소도 서버에서 한 번 처리한다.

서버는 몬스터 ID를 게임 전체에서 재사용하지 않는다. 이전 웨이브 생존자와 늦게 도착한 처치 보고를 구분한다. 클라이언트 풀은 생존자가 남아 있는 경우 확장하며, 처치 확정을 기다리는 슬롯을 재사용하지 않는다. 전투의 총알 충돌/처치 보고 방식은 기존 구조를 사용한다.

## A* 최적화

- 열린 목록의 최소값 선택을 선형 검색에서 이진 최소 힙으로 변경했다. 비용 감소 시 새 항목을 넣고 오래된 항목은 꺼낼 때 무시한다.
- 좌표를 격자 인덱스로 바꿔 비용·부모·방문 상태를 배열에서 O(1)로 조회한다. 노드마다 `new/delete`를 호출하지 않는다.
- 탐색 세대 번호와 재사용 버퍼로 매 탐색의 전체 초기화를 줄인다. 반환 경로는 좌표 값을 소유하므로 다음 탐색에도 유효하다.
- 8방향 이동에 맞는 octile 휴리스틱을 사용한다. 직선 비용은 1, 대각선은 √2이며 벽/터렛 모서리를 통과하지 않는다.
- 방마다 맵 버전과 출발 좌표로 경로를 캐시한다. 목표는 방에서 고정되어 있으며, 장애물이 바뀔 때 캐시를 비운다. 같은 칸의 몬스터와 반복 스폰은 결과를 공유한다.
- 설치 검사에 몬스터별 A*를 반복 실행하던 부분은 한 번의 flood fill로 바꿨다. 온라인 설치 미리보기는 점유 여부를 표시하며 최종 연결성은 서버가 결정한다.

## 패킷

| ID | 이름 | 내용 |
|---|---|---|
| 4002 | `S_MONSTER_PATH` | 몬스터 ID, 맵 버전, 경로/히스토리 개수, int16 좌표 배열. 경로의 0번은 현재 위치이다. |
| 4003 | `S_MONSTER_MOVE` | 몬스터 ID, 맵 버전, 다음 경로 인덱스, 현재 위치, 활성 여부. |
| 4004 | `S_MERGE_TURRET` | 승급할 터렛과 제거할 두 터렛의 좌표, 새 성급. |

클라이언트는 패킷 크기와 배열 개수를 검증하고 해당 몬스터/맵 버전에 결과를 적용한다. 생성 대기 중인 액터에도 경로·합성·판매 결과를 적용한다. 서버 Debug 빌드는 탐색 히스토리도 보내므로 클라이언트 F3에서 볼 수 있다. Release 빌드는 경로만 보낸다. 서버와 클라이언트를 함께 다시 빌드해야 한다.

IOCP 송신은 패킷별 소유 버퍼와 FIFO 큐를 사용한다. 이전 송신 완료 전에는 OVERLAPPED와 버퍼를 재사용하지 않고, 부분 송신 후 나머지를 이어서 보낸다. 큐는 세션당 1 MiB로 제한하며, 취소 완료 전까지 송신 메모리를 유지한다.

## 검증

```powershell
.\Tests\Run-PathfindingTests.ps1
.\Tests\ServerNavigationTests.ps1
```

두 번째 테스트는 빌드된 Debug 서버를 숨겨진 창으로 실행하고 로컬 7777 포트를 사용한다. 약 1분 동안 두 TCP 클라이언트로 설치 거부/롤백, 합성, 경로/위치 일치, 설치·판매 후 재탐색, 처치 중복 방지, 연속 1,000개 방송, 아지트 도착 처리를 확인한다.

A* 테스트는 고정 시드의 무작위 격자에서 독립적인 Dijkstra와 8,000개 경로의 도달 여부·최단 비용을 비교한다. 모서리 통과 금지, 잘못된 입력, 장애물 변경과 반환 경로 수명도 확인한다.

2026-10-14 로컬 `/O2` 측정에서 기존 구현과 각각 1,000번의 캐시 없는 탐색을 비교했다. 양쪽 모두 탐색 히스토리를 기록했다. 기본 50×20 맵은 748 ms → 43 ms(약 17.5배), 지그재그 벽을 추가한 미로는 399 ms → 79 ms(약 5.0배)였다. 이는 해당 환경의 길찾기 함수 측정이며 게임 전체 FPS 측정은 아니다.
