# SK Defense - 기획 및 개발 로그

이 문서는 `CraftEngine` 기반 스타크래프트 '성큰 디펜스' 스타일 게임(프로젝트명: SK Defense) 개발을 위한 기획 및 로그 문서입니다.

## 📌 기능별 구현 플랜 (Implementation Plan)

### 1. 카메라 시스템 및 줌 (WASD 및 확대/축소)
- **WASD 카메라 이동**: `Level` 또는 `GameManager`에 `CameraOffset` 변수를 추가하여 렌더링 시 오프셋을 적용.
- **맵 확대/축소**: Windows API `SetCurrentConsoleFontEx`를 이용해 콘솔 폰트 크기를 변경하여 줌 인/아웃 효과 구현.

### 2. 마우스 입력 및 터렛 설치 (2x2)
- **터렛 미리보기**: `Input::GetMousePosition()`을 가져와 마우스 커서 위치에 2x2 크기의 터렛 설치 가능 여부를 시각적으로 표시.
- **터렛 설치 및 타일 속성 변경**: 클릭 시 터렛 생성 및 맵 그리드(Grid)의 Walkable 상태 업데이트.

### 3. A* 경로 탐색 알고리즘
- **A* 길찾기 로직 구현**: 타일 맵 기반의 최단 경로 탐색 시스템.
- **동적 경로 재탐색**: 터렛이 설치되어 지형이 바뀔 때마다 맵 내 모든 적(Enemy)들의 경로를 갱신하여 터렛을 피해가도록 함.

### 4. 게임 루프 및 자원/웨이브 시스템
- **웨이브 매니저**: 일정 주기마다 적(Enemy) 생성. 웨이브가 올라갈수록 적의 체력/이동속도 증가.
- **재화(Gold) 시스템**: 적 처치 시 골드 획득. 골드를 소비하여 설치된 터렛을 클릭 시 업그레이드 가능.

### 5. 디버그 모드
- **A* 경로 시각화**: 적이 찾은 노드(경로)를 화면에 다른 색상(예: `*`)으로 그려서 시각적 확인.
- **치트키**: 골드 획득(G), 웨이브 스킵(F1) 기능 구현.
